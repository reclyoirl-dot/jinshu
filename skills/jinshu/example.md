:::b-magazine-dropcap{label="新手写作手记 · 第 1 期"}
开号的第一个月，最容易陷入**两种状态**：要么每天改头像、调排版，迟迟不敢发第一篇；要么一口气发了十篇，然后再也坚持不下去。

其实前三十天只需要做好五件小事。它们都不难，但每一件都会在半年后显出分量。
:::

:::t-art-number{no="01" en="POSITIONING" sub="一句话说清楚你在写什么"}
先写定位，再写文章
:::

打开备忘录，写下这句话：「我的公众号，是写给 **谁** 看的，帮他们解决 **什么问题**。」写不出来没关系，先写一个粗糙的版本，发完十篇文章后再回头修改。

:::note-tip{label="小贴士" icon="💡"}
定位越具体越好写。「分享生活」很难坚持，「记录一个上班族的周末城市散步」就能源源不断地写下去。
:::

:::t-art-number{no="02" en="RHYTHM" sub="稳定比数量更重要"}
给自己定一个能坚持的节奏
:::

与其许诺日更，不如选一个三个月后仍然能做到的频率。下面是一个比较稳妥的起步节奏：

:::b-step-cards{title="每周一篇的写作节奏"}
周一：在备忘录里攒选题，记下这周让你有感触的三件事。
周三：挑一个选题写初稿，不追求完美，先写完。
周五：修改、排版，配一张自己拍的图。
周日晚上：定时发布，然后把这一篇彻底放下。
:::

:::t-art-number{no="03" en="LAYOUT" sub="排版是为了让人读完"}
排版只做三件事
:::

好的排版不是花样越多越好，而是让读者**更轻松地读完**。新手只需要注意三点：

- 段落短一点，手机上一屏不超过五行；
- 每篇只用一种标题样式，重点内容才放进卡片；
- 图片和动图服务于内容，不为了热闹而放。

:::b-pros-cons{pros="值得做" cons="先别做"}
统一的标题样式和主色
文末固定的关注引导

每段都换一种卡片
一篇文章放十几个动图
:::

:::t-art-number{no="04" en="DATA" sub="别被第一个月的数字吓到"}
看数据，但别只看数据
:::

第一个月的阅读量大多来自朋友圈和熟人，数字小是正常的。比起阅读量，更值得记录的是下面这几个变化：

:::b-stat-ledger{title="第一个月值得记录的数字"}
4 篇：按时发布的文章数量，这是最重要的指标
12 条：读者留言，每一条都值得认真回复
3 位：主动转发你文章的陌生读者
:::

:::svg-tap-reveal
猜一猜：新号第一个月，最该关注哪个数据？
不是阅读量，而是「完读率」和「留言数」。它们说明有人真的读完了，并且愿意和你说话。
:::

:::t-art-number{no="05" en="CONNECTION" sub="把读者当成朋友"}
认真回复每一条留言
:::

早期读者是最珍贵的。他们的一句「写得真好」，可能就是你坚持下去的理由；他们的一个问题，往往就是下一篇文章的选题。

:::quote-big{author="一位写了五年的作者"}
最初的一百位读者，会决定你未来写成什么样子。
:::

:::divider-text{text="写在最后"}
:::

五件小事说完了。它们看起来普通，却能帮你度过最难的第一个月。如果你也刚刚开始，希望这篇文章能让你少走一点弯路。
