# 三步学会给公众号排版

:::card-gradient{title="写在前面"}
不用懂 HTML，只要会写 Markdown，就能做出好看的公众号文章。
:::

:::title-badge{no="1"}
写内容
:::

在左侧编辑器里用 Markdown 写作：`#` 是标题，`**文字**` 是加粗，`>` 是引用。

:::title-badge{no="2"}
选样式
:::

在「样式中心」挑一个**主题**决定整体风格，再点击**组件**插入标题、卡片、分割线等装饰。

:::img-double
![](https://picsum.photos/seed/wxmd-s1/800/500)
![](https://picsum.photos/seed/wxmd-s2/800/500)
左：选择主题 · 右：插入组件
:::

:::title-badge{no="3"}
一键复制
:::

点击右上角「复制到公众号」，在公众号后台编辑器里 `Ctrl + V` 粘贴即可。

:::title-lines
常见问题
:::

:::qa-faq{no="01"}
图片显示不出来？
请使用公网可访问的图片链接，粘贴后公众号会自动转存。
:::

:::qa-faq{no="02"}
可以修改组件颜色吗？
可以，给组件加上 `{color=#ff6600}` 参数，或者在顶栏修改主色。
:::
