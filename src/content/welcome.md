# 欢迎使用锦书 JinShu

:::card-gradient{title="这是什么？"}
一个**开源**的公众号 Markdown 排版编辑器：左边挑素材，中间写 Markdown，右边实时预览，一键复制到公众号后台。
:::

:::t-art-number{no="01" en="THEMES"}
全局主题
:::

在「样式中心 → 主题」里切换整篇文章的风格，还可以自定义**主色**和**字号**。普通 Markdown 语法都会跟随主题：

> 引用、`行内代码`、**加粗**、*斜体*、~~删除线~~、列表、表格、代码块……

| 语法 | 效果 |
| --- | --- |
| `## 标题` | 二级标题 |
| `> 引用` | 引用块 |

```js
// 代码块会自动高亮，并保留缩进
function hello(name) {
  return `你好，${name}`
}
```

:::t-art-number{no="02" en="MATERIALS"}
海量素材
:::

「素材」里有标题、正文卡片、问答、图文、分割线、引导关注、结尾，还有**动图**和**可点击的 SVG 互动**。点一下就会在光标处插入：

:::svg-tap-reveal
试一试：点一下下面的卡片
这是一个 SVG 点击交互素材，粘贴到公众号后同样可以点击。
:::

:::note-tip{label="素材语法"}
`:::素材名{参数="值"}` 开头，`:::` 结尾，中间写内容。加上 `color=#ff6600` 可以单独修改颜色。
:::

:::qa-classic
外链会怎么处理？
公众号正文不允许外链，像[这个链接](https://github.com)会自动变成文末的参考链接。
:::

:::t-art-number{no="03" en="TEMPLATES"}
整篇模板
:::

没有灵感？在「模板」里挑一篇，会新建一份文档，改改文字就能发。
